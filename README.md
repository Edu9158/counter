# Counter

Counter is a full-stack web application built with React and Node.js.

The goal of this project is to strengthen my understanding of modern web development
concepts, including frontend and backend architecture, REST APIs, version control and
linux-based development workflows.

## Features

- Advanced arithmetic operations;
- Scientific calculator functions;
- Common engineering and financial formulas;
- Calculation history;
- User authentication;
- Responsive user interface;
- Backend API built with Node.js;
- Clean an maintainable code structure;
